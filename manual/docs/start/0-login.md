# 접속과 로그인

## 개요

어드민은 <https://www.214archives.com/admin>에서 등록된 이메일·비밀번호로 로그인합니다. 공개 사이트 반영까지는 게시 후 보통 1~3분이 걸리며, 목록·편집·대시보드 화면은 휴대폰에서도 동작합니다.

## 로그인

![로그인 화면](../img/1.webp)

1. <https://www.214archives.com/admin> 접속
2. 등록된 이메일·비밀번호 입력
3. **로그인** 버튼 클릭

::: warning 주의
로그인 직후 다시 로그인 화면으로 — 계정에 역할이 없음. 관리자에게 등록 요청
:::
