# 공개·초안과 게시의 차이

## 개요

게시물을 사이트에 보여줄지 정하는 "공개 / 초안"과, 그 변경을 실제로 사이트에 내보내는 "변경사항 게시"는 서로 다른 동작입니다. 아래 표로 정리했습니다.

## 딱 두 가지만 기억하기

| | 어디서 | 무엇 |
|---|---|---|
| **공개 / 초안** | 게시물 편집 화면 오른쪽 "공개 상태" 카드 | 이 게시물을 사이트에 **보여줄지** 정하는 표시. 누른다고 바로 사이트가 바뀌진 않음 |
| **변경사항 게시** | 대시보드 "게시 패널" 버튼 | 그동안 만들고·고치고·공개/초안 바꾼 **모든 변경을 한 번에** 사이트로 내보내는 버튼 |

::: tip 팁
즉, **저장·공개는 준비, "변경사항 게시"가 실제 배포.** 여러 개를 고친 뒤 마지막에 한 번만 누르면 됩니다.
:::

## 배지 읽는 법

헤더 오른쪽 `DRIFT · N`{.warning} 배지 = 아직 사이트에 안 나간 변경 개수.

![DRIFT 배지](../img/4.webp)

**변경사항 게시** 후 약 30초 뒤 패널이 `IN SYNC`{.normal}로 바뀌고 배지가 사라짐.
