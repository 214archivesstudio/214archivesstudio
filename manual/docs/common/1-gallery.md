# 갤러리 사진 넣기·순서·설명

## 개요

Showreel을 제외한 섹션에서 사용합니다. 새 포스트 폼의 **갤러리** 블록에서 미리 담아 생성과 함께 저장하거나, 편집 화면 오른쪽 미디어 영역에서 올립니다. 순서를 정하면 1번 카드가 목록·카드 썸네일로 쓰입니다.

## 화면

![미디어 그리드](../img/18.webp)

### A. 카드

올린 순서대로 그리드 끝에 추가됨. **1번 카드가 목록·카드 썸네일**로 쓰임

### B. alt 텍스트

각 카드 아래 **alt 텍스트**에 사진 설명 → 칸에서 나가면 자동 저장("저장됨" 표시)

### C. ✕

사진 빼기: 카드 오른쪽 아래 **✕** → 확인창 **삭제**

## 절차

1. 편집 화면 오른쪽 **미디어 → + 이미지** → 위젯에서 **여러 장 동시 선택** 가능
2. 올린 순서대로 그리드 끝에 추가됨. **1번 카드가 목록·카드 썸네일**로 쓰임
3. 순서 변경: 카드를 **드래그** (휴대폰은 길게 눌러 드래그) · 키보드: Tab → Space → 화살표 → Space
4. 각 카드 아래 **alt 텍스트**에 사진 설명 → 칸에서 나가면 자동 저장("저장됨" 표시)
5. 사진 빼기: 카드 오른쪽 아래 **✕** → 확인창 **삭제**
