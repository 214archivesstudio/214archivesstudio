# 운영 시나리오

여러 작업을 마친 뒤 마지막에 한 번만 [공통 E — 게시](../common/4-publish)하면 되는, 자주 쓰는 운영 흐름 다섯 가지입니다.

### 1. 여러 개 고치고 한 번에 내보내기

![게시 패널 DRIFT](../img/4.webp)

오전에 A 등록·공개, 오후에 B 사진 추가, C 오타 수정 → 배지 `DRIFT · 3`{.warning} → 대시보드 **변경사항 게시** 한 번.

### 2. 게시물 잠깐 내리기

편집 화면 → 공개 상태 **초안** → 확인 → 게시. 나중에 **공개**로 되돌리고 게시하면 복구.

### 3. 사진 한 장 교체

[공통 B — 갤러리](../common/1-gallery)로 ✕ 삭제 → + 이미지로 새 사진 → 드래그로 원래 자리 → 게시.

### 4. 썸네일(대표 이미지) 바꾸기

편집 화면 왼쪽 **썸네일 변경** → 새 이미지 → **저장** → 게시. (갤러리 1번 카드는 목록 썸네일에도 쓰이므로 순서도 함께 확인)

### 5. 게시 후 바로 확인

![게시 패널 IN SYNC](../img/3.webp)
![최근 활동](../img/5.webp)

게시 패널의 **최근 활동 → 실행 로그 ↗**에서 진행 상황을 볼 수 있고, 1~3분 뒤 사이트 새로고침.
