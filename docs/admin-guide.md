# 어드민 사용 가이드 — 시나리오별

> 2026-08-30 기준 (Phase H5 배포본). 카테고리별로 **등록 → 수정 → 삭제** 순서로 정리했습니다. 처음이면 0번만 읽고 바로 카테고리 시나리오로 가세요.

- **어드민**: <https://www.214archives.com/admin> · 등록된 이메일·비밀번호로 로그인
- **공개 사이트 반영까지**: 게시 후 보통 1~3분
- **휴대폰에서도 동작** (목록·편집·대시보드 모두)

---

## 0. 딱 두 가지만 기억하기

| | 어디서 | 무엇 |
|---|---|---|
| **공개 / 초안** | 게시물 편집 화면 오른쪽 "공개 상태" 카드 | 이 게시물을 사이트에 **보여줄지** 정하는 표시. 누른다고 바로 사이트가 바뀌진 않음 |
| **변경사항 게시** | 대시보드 "게시 패널" 버튼 | 그동안 만들고·고치고·공개/초안 바꾼 **모든 변경을 한 번에** 사이트로 내보내는 버튼 |

> 즉, **저장·공개는 준비, "변경사항 게시"가 실제 배포.** 헤더 오른쪽 **DRIFT · N** 배지 = 아직 사이트에 안 나간 변경 개수. 여러 개를 고친 뒤 마지막에 한 번만 누르면 됩니다.

**화면 구성**: `Dashboard`(게시 패널·최근 활동) · `Posts`(목록·검색·섹션 탭·"+ 새 포스트") · 편집 화면(왼쪽 폼 / 오른쪽 공개 상태·미디어 / 맨 아래 위험 영역)

## 1. 모든 카테고리에 공통인 조작

카테고리 시나리오에서 "공통 A"처럼 참조합니다.

### 공통 A — 새 게시물 만들기 (기본 정보)
1. `Posts` → 오른쪽 위 **+ 새 포스트**
2. **섹션 카드** 하나 선택 → 그 섹션에 맞는 폼이 아래에 나타남
3. 공통 입력: **제목** · **슬러그**(영문 소문자·숫자·하이픈, 입력을 멈추면 "사용 가능 / 이미 사용 중" 자동 표시) · **날짜** · 설명(선택)
4. **썸네일** — "이미지를 끌어다 놓거나 파일 선택" → 업로드 위젯에서 이미지 1장 (3:2 권장) · 썸네일 alt(선택)
5. 표시 순서(기본 0, 낮을수록 앞) — 보통 그대로
6. 맨 아래 **생성** → 편집 화면으로 이동하며 "썸네일·기본 정보가 저장됐어요" 토스트

> 빈 필수값으로 생성을 누르면 위에 "입력 N곳을 확인해 주세요"가 뜨고 첫 번째 문제 칸으로 스크롤됩니다. 고치는 즉시 경고가 사라집니다.

### 공통 B — 갤러리 사진 넣기·순서·설명 (Showreel 제외)
1. 편집 화면 오른쪽 **미디어 → + 이미지** → 위젯에서 **여러 장 동시 선택** 가능
2. 올린 순서대로 그리드 끝에 추가됨. **1번 카드가 목록·카드 썸네일**로 쓰임
3. 순서 변경: 카드를 **드래그** (휴대폰은 길게 눌러 드래그) · 키보드: Tab → Space → 화살표 → Space
4. 각 카드 아래 **alt 텍스트**에 사진 설명 → 칸에서 나가면 자동 저장("저장됨" 표시)
5. 사진 빼기: 카드 오른쪽 아래 **✕** → 확인창 **삭제**

### 공통 C — 수정하기
1. `Posts`에서 게시물 제목 클릭 (또는 **편집**)
2. 왼쪽 폼 수정 → 맨 아래 **저장** → "저장했어요" 토스트
3. 사진 추가·삭제·순서는 **공통 B** (저장 버튼 없이 즉시 반영)
4. 사이트에 내보내려면 **공통 E**

### 공통 D — 공개 / 초안 바꾸기
- 오른쪽 **공개 상태** 카드 → **공개** 또는 **초안**
- 초안으로 바꿀 땐 "초안으로 전환할까요?" 확인창이 한 번 뜸 (다음 게시 때 사이트에서 내려감)
- 새로 만든 게시물은 **초안**으로 시작 → 완성 후 **공개**로 바꿔야 사이트에 나감

### 공통 E — 사이트에 내보내기 (게시)
1. 헤더 **DRIFT · N** 배지 클릭 또는 `Dashboard`
2. **게시 패널**에서 무엇이 나갈지 확인 → **변경사항 게시**
3. 약 30초 뒤 패널이 **IN SYNC**로 바뀌고 배지가 사라짐. 최근 활동에 "완료 · 빌드 시작됨 · 1~3분 후 사이트 반영"
4. 1~3분 뒤 사이트에서 확인: `https://www.214archives.com/{섹션}/{슬러그}`

### 공통 F — 삭제하기
- **잠깐 내리기**: 공통 D로 **초안** → 공통 E (게시물은 남고 사이트에서만 사라짐)
- **완전히 지우기**: 편집 화면 맨 아래 **위험 영역 → 삭제…** → 확인창 **삭제** → 공통 E. 되돌릴 수 없음. (`Posts` 목록의 **삭제** 버튼도 동일)

## 2. 카테고리별 시나리오

### Showreel — 대표 영상 1개

| 필수 | 선택 | 갤러리 |
|---|---|---|
| 제목·슬러그·날짜·썸네일·**영상 URL** | 설명 | **없음** (영상 하나만) |

**등록**
1. 공통 A에서 섹션 **Showreel** 선택
2. **영상 URL**에 YouTube 또는 Vimeo 주소 붙여넣기 → 바로 아래 플레이어 미리보기가 뜨면 정상 (안 뜨면 주소 오류)
3. 썸네일 업로드 → **생성**
4. 공개 상태 **공개** → 공통 E

**수정**: 공통 C — 영상을 바꾸려면 영상 URL만 교체 → 저장 → 공통 E
**삭제**: 공통 F

> Showreel은 보통 1개만 운영합니다. 새 쇼릴로 교체할 땐 기존 게시물의 영상 URL·썸네일을 바꾸는 게 가장 간단합니다.

---

### Archives — 여행·도시 사진 묶음

| 필수 | 선택 | 갤러리 |
|---|---|---|
| 제목·슬러그·날짜·썸네일·**도시**·**연도 라벨** | 설명 | 있음 (사진) |

**등록** (예: 도쿄 2025)
1. 공통 A에서 **Archives** 선택 · 제목은 대문자 도시명 권장 (`TOKYO`) · 슬러그 예 `25-tokyo`
2. **도시** `Tokyo` · **연도 라벨** `'25` (제목 옆에 붙는 표기)
3. 썸네일 업로드 → **생성**
4. 편집 화면에서 공통 B로 사진 여러 장 업로드 → 드래그로 순서 정리 → alt 입력
5. 공개 상태 **공개** → 공통 E

**수정**: 공통 C (사진 추가·교체는 공통 B)
**삭제**: 공통 F

---

### Film — 영상 작업 (hover 미리보기 포함)

| 필수 | 선택 | 갤러리 |
|---|---|---|
| 제목·슬러그·날짜·썸네일·**영상 URL** | 설명·**영상 썸네일** | 있음 (사진) |

**등록**
1. 공통 A에서 **Film** 선택 · 슬러그 예 `09-title`
2. **영상 URL** — 본편(YouTube/Vimeo) 주소 → 미리보기 확인
3. **영상 썸네일** — 카드에 마우스를 올리면 재생되는 짧은 영상. "영상을 끌어다 놓거나 파일 선택" → mp4/webm/mov (가로 영상 권장, 200MB 이하). 앞 **10초만** 자동으로 잘라 쓰므로 긴 파일을 그대로 올려도 됨. 업로드 직후 폼 안에서 자동 재생되면 성공 (5~10초 걸릴 수 있음)
   - 이미 Cloudinary URL이 있으면 **고급: URL 직접 입력**에 붙여넣기
4. 썸네일(정지 이미지) 업로드 → **생성**
5. 필요하면 공통 B로 스틸컷 갤러리 추가
6. 공개 상태 **공개** → 공통 E → 사이트 `/film`에서 카드 hover 재생 확인

**수정**: 공통 C — 영상 썸네일만 바꾸려면 **영상 변경** 버튼 → 새 파일 → 저장
**삭제**: 공통 F

---

### Photography — 클라이언트 촬영

| 필수 | 선택 | 갤러리 |
|---|---|---|
| 제목·슬러그·날짜·썸네일·**클라이언트** | 설명 | 있음 (사진) |

**등록**
1. 공통 A에서 **Photography** 선택
2. **클라이언트** 이름 입력 (예 `B.Ready`)
3. 썸네일 업로드 → **생성**
4. 공통 B로 사진 업로드 → 순서·alt
5. 공개 상태 **공개** → 공통 E

**수정**: 공통 C · **삭제**: 공통 F

---

### Personal — 개인 작업 (사진 + 영상 카드)

| 필수 | 선택 | 갤러리 |
|---|---|---|
| 제목·슬러그·날짜·썸네일 | 설명·영상 URL | 있음 (**사진 + 영상 카드**) |

**등록**
1. 공통 A에서 **Personal** 선택 (영상 URL은 비워도 됨)
2. 썸네일 업로드 → **생성**
3. 공통 B로 사진 업로드
4. 영상을 갤러리 카드로 넣으려면 **미디어 → + 영상** → YouTube/Vimeo 주소 → **추가** (YouTube는 카드에 썸네일이 표시됨). 영상 카드도 드래그로 순서 변경·✕로 삭제
5. 공개 상태 **공개** → 공통 E

**수정**: 공통 C · **삭제**: 공통 F

> Personal 외 섹션에는 "+ 영상" 버튼이 없습니다. Film·Showreel의 영상은 폼의 "영상 URL"로 넣습니다.

## 3. 자주 하는 운영 시나리오

**여러 개 고치고 한 번에 내보내기** — 오전에 A 등록·공개, 오후에 B 사진 추가, C 오타 수정 → 배지 **DRIFT · 3** → 대시보드 **변경사항 게시** 한 번.

**게시물 잠깐 내리기** — 편집 화면 → 공개 상태 **초안** → 확인 → 게시. 나중에 **공개**로 되돌리고 게시하면 복구.

**사진 한 장 교체** — 공통 B로 ✕ 삭제 → + 이미지로 새 사진 → 드래그로 원래 자리 → 게시.

**썸네일(대표 이미지) 바꾸기** — 편집 화면 왼쪽 **썸네일 변경** → 새 이미지 → **저장** → 게시. (갤러리 1번 카드는 목록 썸네일에도 쓰이므로 순서도 함께 확인)

**게시 후 바로 확인** — 게시 패널의 **최근 활동 → 실행 로그 ↗**에서 진행 상황을 볼 수 있고, 1~3분 뒤 사이트 새로고침.

## 4. 막혔을 때

| 증상 | 해결 |
|---|---|
| 업로드 위젯이 안 뜸 | 브라우저 팝업 차단 해제 후 재시도 |
| 생성/저장 후 위에 "입력 N곳을 확인해 주세요" | 빨간 밑줄 칸을 채우기. 슬러그는 "이미 사용 중"이면 다른 값으로 |
| 게시했는데 사이트가 그대로 | 1~3분 대기 후 새로고침. 계속 그대로면 대시보드 최근 활동에 **실패**가 있는지 확인 |
| 게시 패널에 **TIMEOUT** | 10분 안에 끝나지 않아 자동 실패 처리. 최근 활동 **실행 로그 ↗**로 원인 확인 후 **다시 게시** |
| 최근 활동에 "GitHub 토큰이 만료됐거나 권한이 없습니다" | 관리자에게 토큰 갱신 요청 |
| Film 영상 썸네일 업로드 직후 미리보기가 비어 있음 | 압축본 생성 중. 5~10초 후 자동 재생 |
| 업로더 대신 회색 안내 박스 / 상단에 "업로드 환경 변수가 비어 있어…" | 환경 변수 누락. 관리자에게 요청 (기존 값은 유지됨) |
| 드래그 정렬이 안 됨 | 조금 더 분명히 잡아 끌기. 휴대폰은 **길게 누른 뒤** 이동. 키보드: Tab → Space → 화살표 → Space |
| 새로고침했더니 입력이 사라짐 | 저장 전 새로고침. 탭을 닫거나 새로고침하기 전에 **저장** |
| 로그인 직후 다시 로그인 화면으로 | 계정에 역할이 없음. 관리자에게 등록 요청 |
| 없는 주소로 들어감 ("찾을 수 없는 페이지입니다") | **포스트 목록으로** 버튼으로 복귀 |

## 5. 게시 전 체크리스트

- [ ] 썸네일이 있고, 갤러리 1번 카드가 대표로 쓸 사진인가
- [ ] 필수 필드(섹션별 표 참고)가 채워졌는가
- [ ] Film이면 영상 썸네일이 폼에서 재생되는가
- [ ] 공개 상태가 **공개**인가 (초안이면 사이트에 안 나감)
- [ ] 대시보드 **변경사항 게시**를 눌렀는가
