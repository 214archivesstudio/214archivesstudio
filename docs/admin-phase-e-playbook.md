# Phase E 본 운영 플레이북

> **목적**: 작가가 개발자 도움 없이 어드민 페이지에서 게시물을 직접 등록 → 갤러리 업로드 → 공개 사이트에 반영까지 완벽하게 할 수 있는지 검증.
>
> **성공 기준**: 막힌 곳이 없이 한 번 완료 → ADR-0001 "비기술 사용자가 직접 운영" 실증 완료.

## 0. 시작하기 전 체크리스트

이것들이 준비되었는지 확인하세요. 준비 상태가 아니면 앞으로 진행할 수 없습니다.

- [ ] **Supabase 로그인 완료** — `/admin/posts` 페이지가 열려 있거나, `/admin` 방문해서 로그인 대화창이 뜸
- [ ] **인터넷 연결 양호** — 브라우저에서 사진이 잘 로딩되는지 확인
- [ ] **약 30–60분 여유** — 이 전체 플레이북을 완료하는 데 필요 (테스트 콘텐츠면 +10분 추가 삭제)
- [ ] **마우스 또는 터치패드** — 사진을 드래그해서 정렬해야 함 (키보드만으로도 가능하지만, 이번엔 마우스 권장)

## 1단계: 새 게시물 만들기

### 목표
새로운 게시물 초안을 만들고 편집 화면으로 들어가기.

### 실행

1. **`/admin/posts` 페이지 열기**
   - 현재 주소창에 `https://214archives.studio/admin/posts` 입력하고 엔터
   - 또는 왼쪽 메뉴의 "Posts" 링크 클릭

2. **우측 상단의 "+ 새 게시물" 버튼 클릭**
   - 초록색 버튼이 보일 것

3. **섹션 선택**
   - 다음 5개 중 하나 선택:
     - `archives` — 과거 프로젝트 (위치, 연도)
     - `film` — 영상 프로젝트 (영상 URL 입력 가능)
     - `photography` — 스튜디오/인물 사진 (의뢰인 이름)
     - `personal` — 개인 작업 (사진 + 영상 모두 가능) ⭐
     - `showreel` — 쇼릴 (갤러리 없음)
   - **이 플레이북에선 `personal` 추천** (사진 + 영상 모두 테스트할 수 있음)

4. **섹션별 필드 입력**
   - `archives`: 도시, 연도, 제목
   - `film`: 제목, 영상 URL (YouTube/Vimeo)
   - `photography`: 제목, 의뢰인
   - `personal`: 제목 (필수), 설명 (선택)
   - `showreel`: 연도, 제목
   - **모두 한국어 입력 가능**

5. **썸네일 업로드 (사진 또는 동영상 커버)**
   - "썸네일 업로드" 버튼 클릭
   - 사진을 선택하거나 드래그해서 놓기
   - 업로드 진행률이 보이고 완료되면 미리보기가 나타남

6. **저장 버튼 클릭**
   - 페이지 우측 하단의 파란색 "저장" 버튼
   - 저장되면 URL이 `/admin/posts/[id]`로 바뀌고, "유저 가이드" 메시지가 상단에 뜬다 (초록색)

### 정상인지 확인

- [ ] 저장 후 URL이 `/admin/posts/[어떤ID]` 형태로 바뀜
- [ ] 좌측 사이드바의 "게시물 정보" 섹션에 방금 입력한 정보가 보임
- [ ] 썸네일 미리보기가 화면에 보임
- [ ] 제목 옆에 "**DRAFT**" 뱃지가 있음 (아직 공개 안 됨)

### 막혔다면?

| 증상 | 해결책 |
|---|---|
| "저장" 버튼이 없거나 비활성화됨 | 필수 필드(섹션, 제목)를 모두 입력했는지 확인. 필드가 빨간 테두리로 표시됨 |
| 썸네일 업로드가 진행 안 됨 | 파일이 10MB 이하 사진인지 확인. 새로고침(Ctrl+R)하고 다시 시도 |
| 저장 후 404 에러 | 어드민 세션이 끊어진 경우. `/admin` 페이지로 돌아가서 다시 로그인 |

## 2단계: 갤러리 사진 업로드

### 목표
게시물에 사진 5–10장을 추가하고 정렬하기.

### 실행

1. **현재 페이지에서 아래로 스크롤**
   - "미디어 매니저" 섹션을 찾기
   - 아무 사진도 없으면 "이미지 추가" 버튼만 보임

2. **"이미지 추가" 버튼 클릭**
   - 클라우드 아이콘이 있는 파란색 버튼
   - 클릭하면 "사진을 선택하거나 여기에 놓기" 대화창이 뜸

3. **사진 선택**
   - **한 번에 여러 장 가능**: 파일 탐색기에서 5–10장 선택 (Ctrl/Cmd + 클릭)
   - 또는 **드래그 앤 드롭**: 파일 탐색기에서 사진들을 대화창으로 드래그
   - **지원 형식**: JPG, PNG, WebP, AVIF (스마트폰 사진 O, BMP 형식 X)

4. **업로드 진행 보기**
   - 각 사진마다 진행률 막대가 보임
   - "업로드 중..." 상태를 기다림 (보통 5–10초)

5. **완료 확인**
   - 미디어 매니저 아래에 썸네일 그리드로 사진들이 추가됨
   - 각 사진 카드에 사진이 미리보기로 보임

### 정상인지 확인

- [ ] 5–10장이 그리드에 순서대로 나타남
- [ ] 각 카드에 사진 미리보기가 보임
- [ ] 각 카드 우측 상단에 "삭제" 버튼(X)이 있음
- [ ] 각 사진 아래 "alt 텍스트" 입력 칸이 있음

### 막혔다면?

| 증상 | 해결책 |
|---|---|
| 업로드 대화창이 안 뜸 | 팝업 차단 해제 확인. 브라우저 주소창 옆의 차단 아이콘 → "차단 해제" |
| "파일 크기 초과" 에러 | 사진이 20MB 이상. 포토샵이나 무료 이미지 크기 조정 사이트(tinypng.com)에서 축약 후 다시 시도 |
| 일부 사진만 업로드됨 | 네트워크가 끊어진 경우. 못 올린 사진만 다시 시도 |
| 업로드는 됐는데 그리드에 안 보임 | 페이지 새로고침(Ctrl+R). 몇 초 기다렸다가 다시 확인 |

## 3단계: 사진 정렬하기

### 목표
사진들을 원하는 순서대로 드래그해서 재배열하기.

### 실행

**방법 1: 마우스 드래그 (권장)**

1. 사진 카드 위에 마우스 올리기
   - 각 카드가 밝아지고 커서가 "손" 모양으로 바뀜

2. 클릭하고 누르고 있기
   - 마우스 좌클릭을 떼지 말 것

3. 원하는 위치로 드래그
   - 카드를 다른 사진 위로 끌어당기기
   - 드래그하면서 다른 카드들이 투명해지고, 삽입할 위치 주변에 선이 표시됨

4. 손가락 떼기
   - 목표 위치 위에서 마우스 좌클릭 떼기
   - 사진이 해당 위치로 이동

5. 모든 정렬이 끝날 때까지 반복

**방법 2: 키보드 (마우스 없을 때)**

1. 이미지 카드에 Tab으로 포커스 이동
2. Space 누르기 → "드래그 모드 진입"
3. ↑ ↓ ← → 화살표 키로 위치 선택
4. Space 다시 누르기 → "여기 놓기"

### 정상인지 확인

- [ ] 드래그 중에 카드가 움직이는 것이 보임
- [ ] 손을 떼면 새 위치에 카드가 고정됨
- [ ] 페이지 새로고침(Ctrl+R) 후에도 순서가 그대로 유지됨

### 막혔다면?

| 증상 | 해결책 |
|---|---|
| 드래그가 안 됨 | 이미지 카드를 확실하게 클릭하고 있는지 확인. 마우스 좌클릭(우클릭 X) 사용 |
| 드래그했는데 제자리로 돌아옴 | 네트워크 연결 확인. 페이지 새로고침 후 다시 시도 |
| 새로고침 후 순서가 원래대로 돌아옴 | 서버 저장에 실패한 경우. 네트워크 정상인지 확인하고 천천히 한두 장씩만 정렬 시도 |

## 4단계: 이미지 설명 추가 (선택, 웹 접근성 위함)

### 목표
각 사진에 짧은 설명(alt 텍스트)을 입력하기. 시각 장애인이 스크린 리더로 사진 내용을 알 수 있도록 돕는 역할.

### 실행

1. 사진 카드 아래의 입력 칸에 클릭
   - "alt 텍스트 입력..."이라고 회색 글씨로 보임

2. 짧은 설명 입력
   - "카페라떼와 노트북" 또는 "서울 강남 야경" 정도면 충분
   - 한국어 입력 가능
   - 필수는 아니므로 비워도 됨

3. 입력을 마치고 **다른 곳을 클릭하거나 Tab 누르기**
   - 자동으로 서버에 저장됨 (화면에 확인 메시지 없음)

### 정상인지 확인

- [ ] 입력 후 칸이 그대로 두어도 에러가 나지 않음
- [ ] 페이지 새로고침 후에도 입력한 텍스트가 그대로 있음

## 5단계: 영상 추가 (personal 섹션만)

### 목표
personal 섹션이면 YouTube 또는 Vimeo 영상 1–2개 추가하기.

**주의**: `archives`, `film`, `photography`, `showreel`에는 영상 기능이 없습니다. 이 단계는 personal만 해당.

### 실행

1. **미디어 매니저 우측의 "영상 추가" 버튼 찾기**
   - personal이면 보임
   - 다른 섹션이면 버튼이 없거나 회색 비활성화 상태

2. **YouTube 또는 Vimeo 영상 URL 준비**
   - YouTube: `https://www.youtube.com/watch?v=...` 또는 `https://youtu.be/...`
   - Vimeo: `https://vimeo.com/...`
   - 공개 설정되어 있는 영상이어야 함

3. **"영상 추가" 버튼 또는 텍스트 필드 클릭**
   - "영상 URL 입력..." 대화창이 뜸

4. **URL 붙여넣기**
   - 동영상 링크 전체를 복사해서 입력 칸에 붙여넣기 (Ctrl/Cmd + V)
   - 예: `https://www.youtube.com/watch?v=abcd1234`

5. **"추가" 버튼 클릭**
   - URL이 유효하면 카드가 미디어 그리드에 추가됨
   - 카드에 "YouTube" 또는 "Vimeo" 아이콘과 영상 ID가 표시됨

### 정상인지 확인

- [ ] 영상 카드가 미디어 그리드 아래에 나타남
- [ ] 카드에 플랫폼 이름(YouTube/Vimeo)과 영상 ID가 보임
- [ ] 페이지 새로고침 후에도 그대로 있음

### 막혔다면?

| 증상 | 해결책 |
|---|---|
| "유효한 YouTube 또는 Vimeo URL이 아닙니다" | URL을 다시 확인. 긴 형식(youtube.com) vs 짧은 형식(youtu.be) 모두 가능. 동영상이 공개 설정인지 확인 |
| 영상 추가 버튼이 보이지 않음 | personal 섹션이 아님. 1단계에서 personal을 선택했는지 확인 |
| 영상 카드가 추가됐다가 사라짐 | 네트워크 끊김. 다시 시도 |

## 6단계: 게시물 공개하기

### 목표
게시물을 "공개 예정" 상태로 전환하고, "사이트에 반영" 버튼으로 실제 공개 사이트에 배포하기.

### 실행

1. **페이지 우측의 "Publish 토글" 찾기**
   - 사이드바 맨 아래 또는 게시물 정보 옆
   - 토글이 **OFF 상태(회색)**로 시작

2. **토글을 ON으로 클릭**
   - 토글이 **파란색**으로 바뀜
   - "공개 예정" 상태 진입

3. **잠깐 기다리기 (1–2초)**
   - 화면이 자동으로 로드되며 대시보드(`/admin`)로 이동할 수 있음
   - 또는 `/admin` 링크를 수동으로 클릭

4. **대시보드에서 "사이트에 반영" 버튼 찾기**
   - 대시보드(`/admin` 페이지) 우측에 파란색 큰 버튼
   - 버튼 위에 "drift" 숫자가 표시 (예: "변경 1건")

5. **"사이트에 반영" 버튼 클릭**
   - 버튼을 누르면 상태가 "진행 중..." 표시로 바뀜
   - 화면 아래 표에 새로운 항목이 추가되고, 상태가 `pending` → `running` → `success`로 변함

6. **완료 대기**
   - 보통 30초~2분 정도 소요
   - 상태가 `success`로 바뀌면 완료
   - "drift" 숫자가 0으로 돌아옴

### 정상인지 확인

- [ ] Publish 토글이 파란색 ON 상태
- [ ] 대시보드의 "사이트에 반영" 버튼을 클릭 가능
- [ ] 버튼 클릭 후 상태 테이블에 "success" 항목 나타남
- [ ] 상태가 "success"로 바뀐 후 drift가 0

### 막혔다면?

| 증상 | 해결책 |
|---|---|
| Publish 토글을 클릭해도 ON이 안 됨 | 현재 계정이 admin 권한이 없는 경우. 정당한 admin 계정으로 로그인되어 있는지 확인 |
| "사이트에 반영" 버튼이 비활성화됨 | 공개할 게시물(published=true)이 없는 경우. Publish 토글을 다시 확인 |
| 버튼 클릭 후 상태가 `failed`로 표시됨 | GitHub 권한 문제. 개발자(Claude)에게 알림 |
| 상태가 `running` 상태에서 멈춤 | 드문 경우. 2–3분 더 기다린 후, 개발자에게 알림 |

## 7단계: 공개 사이트에서 확인하기

### 목표
약 2분 후 공개 사이트(`https://214archives.studio`)에 게시물이 실제로 나타나는지 확인하기.

### 실행

1. **새 탭 또는 새 창 열기**
   - 지금까지 작업한 어드민 탭은 그대로 두기

2. **새 탭에서 공개 사이트 방문**
   - 주소창에 `https://214archives.studio` 입력
   - 또는 `https://214archives.studio/personal` (게시물 섹션 URL)

3. **방금 등록한 섹션 클릭 또는 주소 직접 입력**
   - personal 섹션: `https://214archives.studio/personal`
   - archives 섹션: `https://214archives.studio/archives`
   - 기타: `https://214archives.studio/{섹션이름}`

4. **목록 또는 검색에서 게시물 찾기**
   - 페이지에 게시물 목록이 보임
   - 방금 등록한 게시물의 썸네일이 있는지 확인
   - 최신 게시물일 경우 맨 위에 나타날 가능성이 높음

5. **게시물 클릭해서 상세 페이지 열기**
   - 썸네일이나 제목 클릭
   - `/personal/{게시물-slug}` URL로 이동

6. **내용 확인**
   - [ ] 제목이 올바르게 표시됨
   - [ ] 썸네일이 보임
   - [ ] 업로드한 사진들이 갤러리로 순서대로 표시됨
   - [ ] 영상을 추가했다면, YouTube/Vimeo 영상이 임베드되어 재생 가능한지 확인

### 정상인지 확인

- [ ] 공개 사이트 섹션 페이지에 방금 등록한 게시물이 목록에 나타남
- [ ] 게시물 상세 페이지가 열림
- [ ] 제목, 설명, 갤러리 사진들이 모두 정확하게 표시됨
- [ ] 영상을 추가했다면 재생 가능

### 막혔다면?

| 증상 | 해결책 |
|---|---|
| "사이트에 반영"은 성공했는데 공개 사이트에 안 보임 | Vercel 빌드 진행 중일 수 있음. 2–3분 더 기다린 후 새로고침(Ctrl+R) |
| 공개 사이트 섹션 페이지가 열리지 않음(404) | URL 주소가 정확한지 확인. 예: `/personal` vs `/person` |
| 갤러리에 일부 사진만 보임 | 업로드 실패한 사진이 있을 수 있음. 어드민으로 돌아가서 미디어 매니저 재확인 |
| 영상이 "재생 불가" 상태 | 영상 URL이 공개 설정이 아닐 가능성. 어드민으로 돌아가서 URL 다시 확인 |

## 8단계: 정리 (테스트 콘텐츠인 경우)

### 목표
테스트 목적이었다면 게시물을 삭제하고, 실제 콘텐츠라면 유지.

### 테스트라면: 삭제하기

1. **어드민 대시보드로 돌아가기**
   - 주소창에 `https://214archives.studio/admin/posts` 입력

2. **방금 만든 게시물 찾기**
   - 목록 맨 위(최신)에 있을 가능성 높음

3. **게시물 우측의 "삭제" 버튼(휴지통 아이콘) 클릭**
   - 또는 게시물 클릭 후 우측 상단의 "삭제" 버튼

4. **확인 다이얼로그에서 "삭제" 다시 클릭**
   - "정말 삭제하시겠습니까?" 메시지 확인
   - 확인하면 게시물이 영구 삭제됨

5. **대시보드에서 "사이트에 반영" 버튼 다시 클릭**
   - 삭제된 게시물도 동기화되어야 함
   - 상태가 "success"가 될 때까지 기다림

### 실제 콘텐츠라면: 유지하기

- 그대로 두면 됨
- 나중에 수정이 필요하면 `/admin/posts/[id]`에서 편집 가능
- 비공개로 돌리려면 Publish 토글을 OFF로 → "사이트에 반영" 클릭

## 9단계: 최종 검증 체크리스트

이 모든 것을 확인했으면 Phase E 성공입니다:

- [ ] **게시물 생성** — 새 게시물 만들고 저장 완료
- [ ] **갤러리 업로드** — 사진 5–10장 업로드됨
- [ ] **사진 정렬** — 드래그로 순서 바꿈 (또는 키보드)
- [ ] **영상 추가** (personal만) — YouTube/Vimeo 영상 추가됨
- [ ] **Publish 토글** — 게시물 공개 예정 상태로 전환
- [ ] **사이트에 반영** — 버튼 클릭 → "success" 상태 도달
- [ ] **공개 사이트 확인** — 공개 사이트에서 게시물 완전히 보임
- [ ] **정리** (테스트라면) — 삭제 후 다시 "사이트에 반영"
